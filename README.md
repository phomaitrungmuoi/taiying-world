## 🎮 Elemental Zombies (`/game`)
Game 3D nhập vai đánh zombie bằng nguyên tố (Three.js, không cần build). Mở `game/index.html` qua một static server.
- 6 nguyên tố (Hỏa, Thủy, Phong, Thổ, Băng, Lôi), mỗi hệ 5 chiêu; hạ gục zombie để mở khóa hệ mới.
- 5 ô chiêu (phím 1–5), trộn chiêu của mọi hệ đã mở khóa (Tab); dùng chiêu khác hệ liên tiếp để tăng COMBO.
